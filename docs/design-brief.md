# 카드뉴스 & 릴스 템플릿 디자인 의뢰서

## 프로젝트 개요

Instagram 카드뉴스(캐러셀)와 릴스(숏폼 영상)를 자동 생성하는 시스템입니다.
주제만 입력하면 AI가 리서치 → 카피라이팅 → 렌더링까지 자동으로 처리합니다.
디자이너분께는 **템플릿 디자인**을 의뢰드립니다.

---

## 납품 형태

### HTML/CSS 직접 납품
- 각 타입별 단일 HTML 파일 (외부 의존성 없이 self-contained)
- 플레이스홀더(`{{headline}}`, `{{body}}` 등)를 사용하여 데이터 삽입 위치 표시
- 별도 JS 불필요, CSS만으로 스타일링

| 콘텐츠 | 사이즈 | 용도 |
|---|---|---|

| 릴스 | **1080 × 1920px** | Instagram 릴스 (9:16 풀스크린) |

## 카드뉴스 슬라이드 타입 (14종)

하나의 템플릿 스타일에 아래 14종의 슬라이드 타입이 필요합니다.
각 타입은 용도와 들어가는 텍스트 필드가 다릅니다.

| # | 타입 | 용도 | 텍스트 필드 |
|---|---|---|---|
| 1 | **cover** | 표지 (첫 장) | 대제목, 소제목, 계정명 |
| 2 | **content** | 일반 내용 | 제목, 본문, 슬라이드 번호 |
| 3 | **content-badge** | 카테고리 태그 + 내용 | 배지(TREND 등), 제목, 본문, 부제 |
| 4 | **content-stat** | 숫자/통계 강조 | 제목, 강조 숫자(크게), 본문 |
| 5 | **content-quote** | 인용구/명언 | 출처, 인용문 |
| 6 | **content-image** | 이미지 + 텍스트 | 제목, 본문, 이미지 영역 |
| 7 | **content-steps** | 3단계 프로세스 | 제목, 스텝1/2/3, 본문 |
| 8 | **content-list** | 항목 나열 (최대 5개) | 제목, 항목1~5 |
| 9 | **content-split** | 좌우 비교 | 제목, 왼쪽 제목/본문, 오른쪽 제목/본문 |
| 10 | **content-highlight** | 핵심 강조 박스 | 제목, 강조문, 본문, 부제 |
| 11 | **content-grid** | 2×2 그리드 | 제목, 4개 항목(아이콘+제목+설명) |
| 12 | **content-bigdata** | 거대 숫자 강조 | 제목, 큰 숫자, 단위, 본문 |
| 13 | **content-fullimage** | 풀 배경 이미지 + 오버레이 | 제목, 배지, 본문, 이미지 |
| 14 | **cta** | 마지막 장 (행동 유도) | 제목, CTA 버튼 텍스트, 태그3개, 계정명 |

## 릴스 씬 타입 (8종)

| # | 타입 | 용도 | 텍스트 필드 |
|---|---|---|---|
| 1 | **hook** | 첫 화면 (스크롤 멈추기) | 배지, 대제목, 소제목, 계정명 |
| 2 | **point** | 핵심 포인트 + 번호 | 번호(01 등), 제목, 본문 |
| 3 | **stat** | 숫자/통계 강조 | 라벨, 큰 숫자, 단위, 본문 |
| 4 | **list** | 항목 나열 (3~5개) | 제목, 항목1~5 |
| 5 | **tip** | 팁/노하우 | 아이콘, 제목, 본문(카드) |
| 6 | **comparison** | Before/After 비교 | 제목, 왼쪽(제목+본문), 오른쪽(제목+본문) |
| 7 | **highlight** | 핵심 인사이트 강조 | 라벨, 강조문(카드), 본문 |
| 8 | **cta** | 마지막 화면 (행동 유도) | 제목, 소제목, CTA 버튼, 태그3개, 계정명 |

### 릴스 Safe Zone 주의사항
- **상단 250px**: Instagram 앱 UI(계정명, 뒤로가기 등)가 덮임
- **하단 400px**: Instagram 앱 UI(좋아요, 댓글, 캡션 등)가 덮임
- **핵심 콘텐츠는 중앙 1080×1270px 영역에 배치해주세요**

## 디자인 요구사항

### 공통
- **악센트 컬러가 변수**입니다. 하나의 색상(예: `#3B82F6`)을 기준으로 디자인하되, 색상만 바꾸면 전체 톤이 바뀌도록 설계해주세요
- **계정명 표시 영역** 필요 (예: 하단 또는 상단에 `@my_account`)
- **폰트**: 시스템 폰트 사용 (Apple SD Gothic Neo 또는 Pretendard)
- 텍스트가 동적으로 바뀌므로, **글자수 변동에 유연한 레이아웃** 필요
  - 제목: 최소 4자 ~ 최대 20자
  - 본문: 최소 10자 ~ 최대 80자
- 이미지/사진은 사용하지 않음 (텍스트 + 그래픽 요소만)

### 분위기/레퍼런스
- 타겟: 한국 20~30대 개발자
- 채널: @my_account (개발 인사이트, 테크 뉴스)
- 참고 계정: (여기에 좋아하는 레퍼런스 계정 추가)
- 원하는 느낌: (예: 깔끔하고 전문적 / 임팩트 있고 강렬한 / 미니멀하고 세련된)

### 기존 템플릿 스타일 (참고용)

현재 8종의 카드뉴스 스타일과 3종의 릴스 스타일이 있습니다:

| 스타일 | 배경 | 느낌 |
|---|---|---|
| minimal | 밝은 흰색 | 깔끔, 전문적 |
| bold | 다크 그라디언트 | 강렬, 임팩트 |
| elegant | 블랙 | 고급, 세련 |
| premium | 딥 다크 + 글래스모피즘 | 프리미엄, 현대적 |
| toss | 다크 플랫 | 미니멀, 핀테크 |
| magazine | 포토 + 화이트 | 트렌디, SNS |
| clean | 라이트그레이 | 에디토리얼, 신뢰 |
| blueprint | 라이트블루그레이 | 프레젠테이션 |

**새로운 스타일 1종을 추가로 의뢰합니다.** 기존과 차별화되는 독자적인 스타일을 제안해주세요.
